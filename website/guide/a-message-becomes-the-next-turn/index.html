A message becomes the next turn

Send a durable message into a running agent’s next turn—and get the answer back in the right thread.

What the plate verifies

Shipped capability

Plate lede

Send a durable message to a running session and watch the same stored record arrive inside its terminal as the agent’s next turn. The agent’s answer returns as a reply to the source message.
