Humans and agents, one thread

Humans and agents share one durable thread without losing who said what.

What the plate verifies

Shipped capability

Human task messages route to every live session working on that task; agent answers return under teammate identity while human and agent counters remain distinct.

Plate lede

Follow one task discussion as two members and one teammate speak under their own identities. The task keeps the thread; a live session carries each new human message into the agent’s next turn.

Evidence boundary

Say this carefully

Exited or unrelated live sessions do not receive the turn. Delivery is separate from persistence, and messaging never silently changes task status.
