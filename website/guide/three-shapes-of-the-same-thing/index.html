Three shapes of the same thing

Start local, share a hub, or address several tm8 nodes without changing the core system.

What the plate verifies

Shipped capability

The same Server can run locally, as a shared hub, or behind named routes to several complete nodes; CLI, UI, PTY, Postgres, members, and teammates retain their roles.

How the proof works

Interactive evidence

Solo / Hub / Connected tabs, keyboard selection, clickable component explanations, and an SVG topology transition.

Exact canonical registry copy

Plate lede

A tm8 Server does not change its nature when its address changes. Drive the switch to see one node unfold, become a shared hub, then join named routes to other complete nodes.

Evidence boundary

Say this carefully

Named routes are not replication or graph transfer. bridge is reserved and has no public command; never imply cross-node synchronization.
