02 — Capabilities

Everything you need to run agents as a team.

Maestro is the execution layer around your coding agents — a durable, inspectable command center that survives sleep, reconnects, and hand-offs. Here is what it gives you, at a glance.

  • Orchestrate agents

    Run Claude Code, Codex & Gemini as one coordinated team.

  • Raise & assign tasks

    Turn any outcome into a task and hand it to the right agent.

  • Task lifecycle board

    Track every task through current, pinned, completed & archived.

  • Teams & roles

    Reusable agent personas: coordinators, workers & recruiters.

  • Skills marketplace

    Install skills per project or globally to extend your agents.

  • Execution graphs

    Wire tasks into dependency graphs and run them as workflows.

  • Token analytics

    See token in / out / total across 1h to 30-day windows.

  • Model profiles

    Route work to Balanced, Fast, Heavy or Ultra model tiers.

  • Durable sessions

    Server-owned terminals replay exactly where they stopped.

  • Local-first & inspectable

    Projects, tasks & sessions live as JSON under ~/.maestro/.

Agents drive it too. They run the maestro CLI to create tasks, spawn sessions, report progress, and hand off — on the same control plane you use.

03 — How it works

From intent to reviewed work.

Every run has a clear owner, a defined scope, and an evidence trail. The flow stays legible even when several agents are moving at once.

  1. 01

    Frame the work

    Break an outcome into tasks with dependencies and acceptance criteria.

  2. 02

    Compose the team

    Pick providers, models, roles, permissions, and working directories.

  3. 03

    Run in parallel

    Agents work in real sessions while activity and hand-offs stay visible.

  4. 04

    Review the evidence

    Inspect changes, test results, decisions, and open blockers before you ship.

04 — Principles

Built for serious work.

Local first

Useful without a hosted control plane.

Run the core system on your own machine or your own infrastructure.

Provider neutral

Use the right model for the job.

Orchestration stays separate from any single AI vendor.

Human legible

Know what happened, and why.

Activity, permissions, hand-offs, and evidence are all easy to inspect.

05 — Get started

Build Maestro locally.

Maestro is under active development and open source. Clone the repository, read the code, and run it on infrastructure you control.

Requirements ↗
$ git clone https://github.com/subhangR/agent-maestro.git
$ cd agent-maestro && bun install
$ bun run dev:all

Requires Node.js 18+, Bun, Rust, and the Tauri system prerequisites for the desktop app.
