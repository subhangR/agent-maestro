# Maestro UI — design concept

High-fidelity concept of the Maestro workspace: a conversational **activity view**
(agent steps in plain language, not a raw terminal) in the "Score" design language
(warm paper, agent-green, provider icons, monospace accents).

`maestro-app-ui.html` is a self-contained mockup used as the implementation reference
for the in-app reskin.
